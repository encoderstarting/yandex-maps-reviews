# Правила разработки фронтенда

## Назначение

Каталог содержит отдельное Vue 3 SPA. Бэкенд доступен через URL из `VITE_API_URL`.

## Vue и интерфейс

- Использовать Vue 3 и Composition API с `<script setup>`.
- Пользовательские тексты, ошибки, подписи и состояния интерфейса писать на русском языке.
- Явно показывать загрузку, пустые данные, ошибку и повторную попытку.
- Не хранить серверные данные в компонентах дольше необходимого; при росте приложения вынести API-клиент и состояние в отдельные модули.
- Не вставлять непроверенный HTML из отзывов через `v-html`.

## Стили

- Использовать Tailwind CSS 4 и CSS-first настройку через `@theme`.
- Не создавать `tailwind.config.js` без реальной необходимости.
- Для расстояний между соседними элементами предпочитать `gap`.
- Интерфейс должен оставаться работоспособным от ширины 320 пикселей.

## API и аутентификация

- Все запросы отправлять через общий Axios-клиент с `withCredentials` и `withXSRFToken`.
- Перед входом получать CSRF cookie через `/sanctum/csrf-cookie`.
- Не хранить пароль, cookie или токен Sanctum в `localStorage`.
- Ошибки валидации 422 показывать рядом с соответствующими полями.

## Проверки

После изменений выполнить:

```bash
pnpm run build
pnpm audit --prod
```

При добавлении тестового инструментария проверять пользовательское поведение, а не внутреннее устройство компонента.
