# Фронтенд Yandex Reviews

Отдельное Vue 3 SPA для входа, подключения организации, просмотра хода синхронизации и отзывов. Приложение не содержит Laravel-шаблонов и общается с бэкендом только по HTTP.

## Требования

- Node.js 22.13 или новее;
- pnpm 11.19.

## Запуск

До запуска SPA поднимите API и worker по инструкции из [`../backend/README.md`](../backend/README.md).

```bash
cp .env.example .env
pnpm install
pnpm dev
```

В `.env` указывается адрес Laravel API:

```dotenv
VITE_API_URL=http://localhost:8000
```

## Сборка и аудит

```bash
pnpm test
pnpm run build
pnpm audit --prod
```

Sanctum работает через HTTP-only cookie. Axios настроен с `withCredentials` и `withXSRFToken`; хранить авторизационные данные в `localStorage` не требуется.

## Production-контейнер

Файл [`Dockerfile`](Dockerfile) собирает статические файлы SPA и переносит их в небольшой Nginx-образ. В production `VITE_API_URL` оставляется пустым: браузер обращается к API на том же HTTPS-домене, а Caddy направляет служебные маршруты в Laravel. Благодаря этому не требуется междоменная настройка cookie.

Полный запуск всех контейнеров на VPS описан в [`../deploy/README.md`](../deploy/README.md).

## Структура

- `src/App.vue` — экран входа, форма ссылки, polling, карточка и отзывы;
- `src/api/client.js` — единый Axios-клиент для Sanctum и API;
- `src/style.css` — глобальные стили и Tailwind CSS 4;
- `src/App.test.js` — проверки основных пользовательских сценариев.

## Подключение компании

После входа пользователь вставляет HTTPS-ссылку на карточку в Яндекс Картах. Ошибка валидации `422` показывается под полем. После успешного добавления интерфейс раз в 1,5 секунды запрашивает статус, пока синхронизация не завершится. После конечного статуса polling останавливается.

Интерфейс различает ожидание, работу, успех, блокировку, изменение источника и общий сбой. HTTP 401 возвращает пользователя на экран входа, а сетевая ошибка показывает понятное сообщение.

## Карточка и отзывы

После синхронизации карточка показывает средний рейтинг, количество оценок и количество отзывов отдельно. Для каждого отзыва выводятся автор, дата, текст и оценка. Бэкенд возвращает по 50 отзывов, а кнопки «Назад» и «Вперёд» подгружают нужную страницу без перезагрузки SPA.

## Ограничения

Это одноэкранный прототип: он не содержит отдельного router или глобального store. При росте приложения стоит вынести экраны в маршруты, а состояние авторизации и организаций — в composables или store. Для сдачи текущего тестового это не требуется.
