# Правила работы с репозиторием

## Язык

- Общение с пользователем, документация, описания задач, сообщения об ошибках интерфейса и новые комментарии пишутся на русском языке.
- Имена классов, методов, переменных, таблиц, полей API и технических сущностей остаются на английском языке по правилам Laravel, PHP и JavaScript.
- Общепринятые названия технологий и протоколов не переводятся искусственно.

## Структура

- `backend/` — самостоятельное Laravel API.
- `frontend/` — самостоятельное Vue 3 SPA.
- Общая документация и план находятся в корне.
- Не смешивать зависимости: Composer запускается только в `backend/`, менеджер JavaScript-пакетов — только в `frontend/`.

## Общие требования

- Перед изменениями прочитать ближайший `AGENTS.md` в затрагиваемом каталоге.
- Не помещать бизнес-логику в маршруты и контроллеры.
- Не коммитить `.env`, секреты, `vendor`, `node_modules`, собранные файлы и временные базы.
- Любое изменение поведения сопровождается минимальным полезным тестом.
- После работы выполнить проверки обеих затронутых частей и кратко перечислить их результат.
- Не реализовывать обход защит внешнего сервиса без явного описания рисков, ограничений и правил эксплуатации.

## Документация

- При изменении структуры, переменных окружения или команд запуска обновить корневой `README.md` и README соответствующей части.
- Статус требований отмечать в `task.md` только после фактической реализации и проверки.
- Документация должна честно отделять готовое от запланированного.
